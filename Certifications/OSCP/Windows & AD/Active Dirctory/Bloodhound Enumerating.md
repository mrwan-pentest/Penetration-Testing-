# BloodHound Enumeration

## Overview

**BloodHound** is used to analyze Active Directory by collecting information about users, groups, computers, permissions, and their relationships.

We can use **NetExec (`nxc`)** to enumerate the Active Directory and collect the data that BloodHound needs for analysis.

The general workflow is:

```
NetExec
   ↓
Collect Active Directory Data
   ↓
BloodHound
   ↓
Analyze Relationships and Attack Paths
```

---

## Step 1: Identify the Domain

First, use NetExec to enumerate the SMB service and identify basic domain information:

```
nxc smb 192.168.227.139
```

This provides information about the target, including the **Domain** and **Hostname**.

---

## Step 2: Enumerate Users

To list the users in the domain:

```
nxc smb 192.168.227.139 -u user1 -p '12345l**' --users
```

The `--users` option queries the target for domain user accounts.

---

## Step 3: Enumerate Groups

To list the groups in the Active Directory:

```
nxc ldap 192.168.227.139 -u user1 -p '12345l**' --groups
```

This helps identify groups and understand the basic structure of the domain.

---

## Step 4: Collect BloodHound Data

NetExec can collect detailed Active Directory information and save it in a format that BloodHound can analyze.

Use:

```
nxc ldap 192.168.227.139 -u user1 -p '12345l**' --bloodhound -c All --dns-server 192.168.227.139
```

### Important Options

- `--bloodhound` — Enables BloodHound data collection.
- `-c All` — Collects all supported BloodHound data.
- `--dns-server` — Specifies the DNS server to use.

The command generates a **ZIP file** containing the collected Active Directory data.

---

# Step 5: Start BloodHound

BloodHound uses **Neo4j** as its database.

Start Neo4j:

```
sudo neo4j start
```

Then start BloodHound:

```
bloodhound-start
```

Open the BloodHound web interface in the browser.

---

## Step 6: Import the Data

From the BloodHound interface:

```
Administration → Ingest
```

Upload the ZIP file generated by NetExec.

![](../../../../Images/Pasted%20image%2020260927233815.png)

After the data is imported, BloodHound can analyze the collected Active Directory information.

---

## Step 7: Search and Analyze

Go to:

```
Explore → Search
```

From here, you can search for:

- Users
- Groups
- Computers
- Domains
- Other Active Directory objects

![](../../../../Images/Pasted%20image%2020260927233908.png)

You can then inspect the **relationships** between objects, such as group membership and permissions.

This is one of the main purposes of BloodHound: instead of viewing AD information as separate pieces, it represents the relationships as a **graph**, making potential paths between objects easier to understand.
