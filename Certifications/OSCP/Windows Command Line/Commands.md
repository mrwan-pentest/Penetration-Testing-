
## To list all available commands

```
help
```

## To know information about the command

```
help <command>
OR
<command> /?
```

## To list the history 

```
doskey history
```


## To list the structure of the folders

```
tree
```

## To create a new Folder

```
md Folder name
OR
mkdir Folder name
```

## To remove a Folder

```
rd Folder name
OR 
rmdir Folder name
```

## To remove a file 

```
del file name
```

## To move a Folder or a File

```
move <folder name> <path name>
```

## To copy a file  

```
copy < file nmme > <path name>
```

## To copy all files and folders within the folder

```
xcopy <name> <pathname> /E
```

## To read files

```
more >>Page by page
type >> read all the content 
```

## To create a new file

```
echo "content" > file name
OR 
fsutil file createNew file name <length>
```

## To rename a file or a filder

```
ren <old name> <new name>
```

## To search for a specific word in a file

```
find /i "Word" < file name
```
