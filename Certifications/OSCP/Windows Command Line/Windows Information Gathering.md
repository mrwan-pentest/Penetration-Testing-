
## To know information about the system

```
systeminfo
```

## To display the name of the device

```
hostname
```

## To display the version 

```
ver
```

## To display the IP address you contact with them

```
arp /a
```

## To display all the groups we are in

```
whoami /groups
```

## To display all the groups in the system

```
net localgroup
```

## To display info about shared resources on the host and to create new shared resources as well.

```
net share
```

## To find any program

```
where program.exe
```

## To search for file put inside specific path

```
where -R <path>
```

## To create a variable

```
set command for local variables  this command create a new variable 
set name=anything

Setx command for Global Variables this command makes a local variable global
setx local veriable value
```
